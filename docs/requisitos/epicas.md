# Épicas

## EP1 - Gestión de Ciudadanos y Autenticación

Incluye:
- Registro de ciudadanos.
- Inicio de sesión.
- Validación de identidad mediante API docente.
- Registro de intentos fraudulentos.
- Control de roles y permisos.

## EP2 - Gestión de Reclamos Ciudadanos

Incluye:
- Creación de reclamos.
- Selección del tipo de incidente.
- Descripción del problema.
- Geolocalización automática.
- Carga de fotografías o videos.
- Consulta del estado del reclamo.
- Historial de reclamos del ciudadano.

## EP3 - Gestión Administrativa de la Comuna

Incluye:
- Visualización de reclamos registrados.
- Dashboard administrativo.
- Tablero Kanban.
- Gestión del ciclo de vida del reclamo.
- Cambio de estados.
- Aprobación o rechazo de reclamos resueltos.

## EP4 - Gestión de Equipos y Proveedores

Incluye:
- Visualización de tareas asignadas.
- Inicio de tareas.
- Finalización de tareas.
- Registro de materiales utilizados.
- Registro de observaciones técnicas.
- Carga de evidencias de resolución.
- Reatención de tareas rechazadas.

## EP5 - Notificaciones y Seguimiento

Incluye:
- Notificaciones al ciudadano.
- Avisos por cambios de estado.
- Seguimiento del avance del reclamo.
- Comunicación básica entre el sistema y los usuarios.

## EP6 - Reportes Estadísticos

Incluye:
- Reportes de reclamos por estado.
- Reportes de reclamos por equipo o proveedor.
- Reportes de trabajos pendientes.
- Reportes de tiempos de resolución.
- Reportes de incumplimientos o demoras.

## EP7 - Auditoría, Seguridad y Protección de Datos

Incluye:
- Historial inmutable de actividad.
- Registro de cambios de estado.
- Trazabilidad de acciones.
- Validación de entradas.
- Protección de datos personales.
- Acceso seguro mediante JWT o Laravel Sanctum.
- Buenas prácticas de seguridad.

## EP8 - Infraestructura, Backend y API

Incluye:
- Configuración de Laravel.
- Configuración de MySQL.
- Migraciones.
- Modelo de datos.
- API REST.
- Endpoints de autenticación.
- Endpoints de reclamos.
- Endpoints de evidencias.
- Almacenamiento de archivos multimedia.

## EP9 - Testing y Documentación Técnica

Incluye:
- Pruebas funcionales.
- Pruebas de autenticación.
- Pruebas de validación de identidad.
- Pruebas del flujo de estados.
- Pruebas de seguridad.
- Documentación de requisitos.
- Documentación de API.
- Documentación de seguridad.
- Documentación de testing.
