# Priorización del Backlog

## Valor de Negocio

| Valor | Descripción |
|---------|-------------|
| Muy Alto | Funcionalidad indispensable para cumplir el objetivo principal del sistema. |
| Alto | Funcionalidad importante para la operación normal del sistema. |
| Medio | Funcionalidad complementaria que agrega valor pero no impide el funcionamiento principal. |

## Estimación de Esfuerzo

Las historias fueron estimadas mediante Planning Poker por los integrantes del equipo.

| Story Points | Interpretación |
|-------------|----------------|
| 1 - 5 | Bajo |
| 6 - 10 | Medio |
| 11 - 15 | Alto |
| 16 o más | Muy Alto |
