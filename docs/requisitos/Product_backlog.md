# Product Backlog Inicial
Historias de Usuario
HU1	Como Ciudadano, quiero registrar un reclamo con descripción, ubicación y evidencia, para informar un problema a la comuna.
HU2	Como Ciudadano, quiero consultar el estado de mis reclamos, para conocer su avance.
HU3	Como Ciudadano, quiero recibir notificaciones sobre cambios en mis reclamos, para estar informado.
HU4	Como Comuna, quiero visualizar todos los reclamos registrados, para gestionar las solicitudes ciudadanas.
HU5	Como Comuna, quiero asignar reclamos a equipos de trabajo, para atenderlos de forma organizada.
HU6	Como Comuna, quiero aprobar o rechazar reclamos resueltos, para validar su correcta atención.
HU7	Como Equipo, quiero visualizar las tareas que me fueron asignadas, para planificar mi trabajo.
HU8	Como Equipo, quiero marcar el inicio de una tarea, para registrar que el trabajo está en proceso.
HU9	Como Equipo, quiero registrar la finalización de una tarea con observaciones y evidencias, para informar su resolución.
