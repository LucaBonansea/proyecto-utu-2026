#### 1. Objetivo y resultado

**Objetivo acordado:**  
Desarrollar un sistema web para la gestión de reclamos asociados a edificios públicos que permita optimizar el registro, seguimiento y administración de las incidencias reportadas, mejorando la organización interna de la Intendencia y la comunicación con los Usuarios de edificio.

**Resultado obtenido:**  
Se obtuvo una aplicación web funcional que permite registrar y gestionar reclamos, realizar el seguimiento de su estado, adjuntar evidencias fotográficas y administrar usuarios, edificios, proveedores y clasificaciones. Además, el sistema incorpora herramientas de administración para organizar las incidencias y facilitar su seguimiento, junto con funcionalidades de notificaciones y gestión de prioridades. El producto cuenta con una interfaz adaptada a distintos dispositivos y una estructura que permite centralizar la información y mejorar la organización del mantenimiento de los edificios públicos.

#### 5. Lecciones aprendidas

- **Funcionó bien:** El uso de Git y GitHub para el control de versiones, la planificación del trabajo mediante sprints y la colaboración para resolver problemas durante el desarrollo del sistema.

- **Debe mejorarse:** La organización y coordinación del equipo, especialmente en la comunicación y la distribución de las tareas y responsabilidades, para facilitar el seguimiento del trabajo y evitar dificultades durante el desarrollo.

- **Recomendación futura:** Definir las responsabilidades de cada integrante desde el inicio del proyecto y establecer una planificación más detallada de las tareas y los tiempos. Además, aplicar los aprendizajes adquiridos en el desarrollo integral de aplicaciones web, la gestión de bases de datos, la integración entre frontend y backend, el uso de herramientas de control de versiones y las pruebas del sistema.
