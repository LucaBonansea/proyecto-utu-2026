Redefinir y reestructurar la documentación del proyecto incorporando las **épicas** desarrolladas a partir de la información obtenida en las entrevistas con el cliente, eliminando la documentación obsoleta y creando el **Project Charter** y los nuevos archivos de requerimientos.

## Temas Tratados

1. **Depuración de documentación obsoleta:** Se identificaron y eliminaron del repositorio los archivos que ya no representaban el alcance actual del proyecto:
   * `estimacion-epicas.md`
   * `priorizacion-backlog.md`
   * `requisitos.md`
   * `sprint-planning.md`
2. **Elaboración del Project Charter:** Creación del Acta de Constitución del Proyecto (*Project Charter*), detallando el alcance, *stakeholders*, riesgos y objetivos estratégicos.
3. **Definición de requerimientos y épicas:** Redacción de la nueva documentación de requerimientos funcionales y no funcionales, estructurados mediante épicas e historias de usuario.
4. **Resumen de requerimientos para la primera entrega:** Creación de un documento de texto que consolida los requerimientos para la primera entrega del proyecto a través de las distintas asignaturas.

---

## Acuerdos

* Eliminar de forma definitiva los archivos obsoletos del repositorio para evitar inconsistencias en el flujo de trabajo.
* Adoptar formalmente el nuevo *Project Charter* como documento base del proyecto.
* Utilizar la nueva estructura de épicas e historias de usuario para guiar las iteraciones de desarrollo.
* Coordinar las entregas del proyecto alineando los requisitos técnicos con las exigencias académicas de las diferentes materias.
