## Temas Tratados

1. **Reorganización del repositorio:** Se analizó la documentación y los archivos existentes, determinando cuáles continúan siendo relevantes para el desarrollo del proyecto y cuáles debían eliminarse por haber sido elaborados antes de contar con la información obtenida en la entrevista con el cliente.

2. **Desarrollo del sistema:** Se planificó la implementación de nuevas funcionalidades relacionadas con la interfaz principal del sistema y la experiencia de usuario.

3. **Seguridad del proyecto:** Se definieron las tareas vinculadas al análisis de riesgos y a la incorporación de buenas prácticas de seguridad.

4. **Diseño de interfaces por roles:** Se estableció el desarrollo de las interfaces específicas para los distintos tipos de usuarios del sistema.

5. **Avances técnicos del proyecto:** Se presentó el trabajo realizado por Thiago Carbajal y Luca Bonansea, quienes lograron convertir la aplicación en una **Progressive Web App (PWA)**, permitiendo que el sistema pueda instalarse y ejecutarse como una aplicación en dispositivos compatibles. Además, se implementó el despliegue mediante **GitHub Pages** utilizando el protocolo **HTTPS**, con el objetivo de disponer de un entorno seguro para la fase de **Beta Testing**.
