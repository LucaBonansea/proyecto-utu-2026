# Análisis de Riesgos del Proyecto

## Riesgos Técnicos

| Riesgo                                                 | Impacto | Mitigación                                                                      |
| ------------------------------------------------------ | ------- | ------------------------------------------------------------------------------- |
| Problemas de integración con la API docente            | Alto    | Realizar pruebas tempranas y revisar la documentación de la API.                |
| Errores en la carga de evidencias multimedia           | Medio   | Implementar validaciones y pruebas de carga de archivos.                        |
| Problemas de compatibilidad entre tecnologías          | Medio   | Definir el entorno de desarrollo desde el inicio y realizar pruebas frecuentes. |
| Pérdida de información por errores en la base de datos | Alto    | Realizar respaldos periódicos y pruebas de recuperación.                        |

## Riesgos Organizativos

| Riesgo                                   | Impacto | Mitigación                                                             |
| ---------------------------------------- | ------- | ---------------------------------------------------------------------- |
| Ausencia de integrantes del equipo       | Alto    | Compartir conocimiento y documentar el trabajo realizado.              |
| Retrasos en la entrega de tareas         | Alto    | Dividir tareas en actividades pequeñas y realizar seguimiento semanal. |
| Problemas de comunicación                | Medio   | Mantener reuniones periódicas y actualizar GitHub Projects.            |
| Cambios de alcance durante el desarrollo | Medio   | Validar requisitos antes de iniciar cada sprint.                       |

## Acciones de Mitigación

1. Mantener actualizado el tablero Kanban.
2. Realizar commits frecuentes en GitHub.
3. Utilizar ramas de trabajo y Pull Requests.
4. Documentar decisiones técnicas importantes.
5. Realizar pruebas continuas durante cada sprint.
6. Mantener reuniones de seguimiento del equipo.
